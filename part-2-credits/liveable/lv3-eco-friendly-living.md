# LV3: Eco-Friendly Living

## Aim

_To encourage and promote developments that provide a safe and sustainable community that promotes an active lifestyle._

| Points Available   | 2    |
| ------------------ | ---- |
| Mandatory Minimums | None |
| Project-wide       | Yes  |

## Credit Criteria

Up to two points are available in total across the eco living and safety checklists below. There is no requirement to target a minimum number of points in either checklist, however each checklist has a maximum number of points that can be targeted from it.

### Design and Built Rating

Completed Pro forma of Credit Compliance OR evidence as listed in Pro forma.

## Assessment

For standalone and terraced dwellings, each individual dwelling must have the feature for which points are being claimed. For Design ratings, use plans and specification to establish features that will be present on the property. For Built Rating, inspect on site.

#### Vegetable garden areas

The area measured is the total area used or designated for vegetable planting. Make an assumption where the planted area is not clearly defined and /or there is mixed planting.

#### Fruit trees

When counting fruit trees do not include those where the fruit is purely ornamental; however, include if at all edible.

#### Capacity of waste facilities

To be counted for points, communal waste facilities should be sufficiently sized for the number of dwellings that will utilize them. Rubbish and food waste storage facilities must have capacity for storing a total of 50L per dwelling per week in between collections, and recycling storage facilities must have capacity for storing 40L per dwelling served. Rubbish and recycling should not be comingled, and waste storage containers should have clear labelling designating what type of waste /recyclables /food waste, etc are accepted.

#### Safety Features

For multi-unit developments or communal housing, safety features should be assessed on the overall site rather than each individual dwelling. For large developments with a number of standalone homes, compliance maybe assessed on each dwelling (in this case all dwellings should comply individually), or on the overall site.
