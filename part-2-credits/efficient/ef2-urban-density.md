# EF2: Urban Density

## Aim

_To promote developments with smaller footprints, recognising the benefits of denser urban planning such as affordability and efficiencies in infrastructure and space utilization._

## Credit Summary

| Points Available   | 3    |
| ------------------ | ---- |
| Mandatory Minimums | None |
| Project-wide       | Yes  |
| Calculator         | Yes  |

## Credit Criteria

Where the ratio of [gross floor area (GFA)](#user-content-fn-1)[^1] to [building footprint (BF)](#user-content-fn-2)[^2] is two or more, use the following table to determine the points.

## Assessment

{% stepper %}
{% step %}
Calculate the building footprint (BF) and gross floor area (GFA) using floor plan drawings.
{% endstep %}

{% step %}
Divide the GFA by the BF to obtain the density ratio and round this figure down to the nearest whole number.
{% endstep %}

{% step %}
Use the [credit criteria](ef2-urban-density.md#credit-criteria) table to determine the number of points.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
For [multi-unit developments](#user-content-fn-3)[^3], add together the total GFA of all buildings and the BF of all buildings.

Divide the total project GFA by the total project BF.
{% endhint %}

{% hint style="info" %}
For [mixed-use developments](#user-content-fn-4)[^4], include the non-residential areas when completing the calculations.
{% endhint %}
